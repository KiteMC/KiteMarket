# KiteMarket product icon

Original artwork: moss-green cloth awning, wooden stall, gold trading plate. No
lettering, no third-party artwork, no official IA theme assets.

- Editable source: `kitemarket-icon.svg` (64 × 64 pixel grid).
- Transparent exports: `kitemarket-icon-{1024,512,128}.png`.
- Re-export: `python branding/export-icon.py` with Python 3 and Pillow.
- Use the 128 export for small cards; use SVG or the larger exports for websites,
  product pages, and repository branding. Do not stretch into a different ratio.
